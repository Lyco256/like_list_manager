# `.gitignore`

## 対応ソース

`.gitignore`

## 役割

Gradleキャッシュ、ビルド成果物、端末固有設定、Android Studio設定、APKなどをGit管理から除外します。

## 関連ファイル

- `gradle.properties`: Gradle実行時の共通設定です。
- `app/build.gradle.kts`: `build/` やAPKを生成します。
- `gradlew`, `gradlew.bat`: 除外対象のGradleキャッシュを利用します。

## 変更時の確認

秘密情報や端末固有ファイルを追加する場合は、コミット前に `git status --short` で追跡対象を確認します。

`test-device.local.properties` の実機serialと `device-recovery-snapshot/` の非公開DB・画像はGit管理しません。
