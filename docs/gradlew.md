# `gradlew`

## 対応ソース

`gradlew`

## 役割

macOS/Linux向けGradle Wrapper起動スクリプトです。指定されたGradle版で同じビルドを再現します。

## 関連ファイル

- `docs/gradlew.bat.md`: Windows版の同等スクリプトです。
- `docs/gradle/wrapper/gradle-wrapper.jar.md`: Wrapper実行本体です。
- `docs/gradle/wrapper/gradle-wrapper.properties.md`: Gradle配布URLを定義します。

## 変更時の確認

通常は手編集せず、Gradle Wrapper更新コマンドで関連3ファイルとまとめて更新します。
